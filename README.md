# GIS
Membangun *School Geographic Information System*  dengan menggunakan framework **Flask** dan bahasa pemrograman **Python** untuk menghitung dan menampilkan jarak/rute dari lokasi pengguna ke sekolah-sekolah.


## Tugas dan Tanggung jawab:<br> 
1. Melakukan riset terhadap beberapa metode perhitungan jarak<br>
2. Mengintegrasikan salah satu metode dengan hasil paling efektif dan efisien<br>


Hasil dari perbandingan beberapa metode perhitungan jarak telah saya dokumentasikan pada sebuah artikel jurnal yang berjudul<br> ***Analisis Perbandingan Algoritma Dijkstra, Haversine, dan Distance Matrix API pada Penentuan Jarak Sekolah di Kota Semarang*** dengan kesimpulan "Menggunakan Algoritma Dijkstra dengan memanfaatkan data dari OpenStreetMap mampu menurunkan error sebesar 50 persen dibandingkan metode Haversine dengan Distance Matrix API sebagai Gold Standard. Selain itu, berbeda dengan Distance Matrix API yang memerlukan koneksi dan dapat menimbulkan biaya, algoritma dijkstra dapat digunakan secara offline dan sepenuhnya gratis." <br>
